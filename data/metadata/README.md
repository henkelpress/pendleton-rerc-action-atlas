# Pendleton County Community Data Atlas GIS metadata

This folder documents the four public ArcGIS web maps embedded in the atlas.

- `metadata_manifest.json` records extent, CRS, lineage, stewardship, use constraints, layer inventory, and claim limits.
- `data_dictionary.csv` defines the project-maintained public popup fields. External agency services retain their source-native schemas and metadata.

The map collection supports exploration. It does not rank projects, determine eligibility, establish ownership or access, make parcel-level flood determinations, certify safety conditions, or guarantee a complete inventory of every facility, trail, park, or tourism place.

- water_resources_data_dictionary.csv defines the public HUC-12, EPA ATTAINS, and National Inventory of Dams popup fields and claim limits.
